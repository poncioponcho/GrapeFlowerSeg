# 测试集A数据说明

本压缩包只包含A榜测试输入，不包含训练集，也不包含任何测试标签、掩码、忽略区域真值、答案或评分脚本。

## 目录结构

```text
测试集A/
├── testA/
│   └── images/             # 94张A榜测试图像
├── images_testA.json       # 仅含文件名、图像ID和宽高
└── README_数据说明.md
```

`images_testA.json`是无标签元数据，只用于核对图像文件名和尺寸，不包含实例类别或分割信息。

参赛者应对94张图像全部生成预测，并按提交样例说明直接上传`result.json`。
