# 测试集 B 说明

本压缩包只包含测试输入和无答案图像清单，不包含真实类别、实例掩码、
忽略区域或任何测试答案。

- `testB/images/`：106 张 JPG 图像，尺寸均为宽 2048 × 高 1152。
- `images_test_b.json`：图像文件名、宽、高组成的无答案清单。

106 张图像由 53 张原图与对应的 53 张翻转增强图组成，全部参与评测。
原图为 `IMG_332.jpg` 至 `IMG_384.jpg`，增强图带 `_aug1.jpg` 后缀。
请对全部 106 张图像输出预测，不要遗漏增强图；图像没有预测实例时，
也必须保留该图像的结果记录，并将 `instances` 设为空列表。

`image_id` 使用完整文件名（包含 `.jpg`），不能改名或只填写数字编号。
掩码需恢复到原图分辨率，COCO compressed RLE 的 `size` 为 `[1152, 2048]`，
依次表示高、宽。

提交格式、模型版本声明及校验方法见另行发布的提交样例与提交说明。
不要把测试图像、数据清单或本说明打入正式提交包。
