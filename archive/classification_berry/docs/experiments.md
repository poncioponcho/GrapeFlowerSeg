# Experiment log

Discipline (inherited from the HardLane repo): **one variable per experiment**,
and every entry records the command, the number, and the decision it drove. An
experiment without a recorded OOF Macro-F1 is not an experiment.

Reporting rule: only **grouped-OOF Macro-F1** counts as evidence for model
selection. A number measured under a non-grouped split is recorded as `LEAKY`
and may never justify a decision.

---

```
### YYYY-MM-DD · <one-line hypothesis>

- result    : OOF Macro-F1 = 0.xxxxx  (Δ vs. previous = +x.xx pp)
- confusion : 0->1 = n, 1->0 = n, 1->2 = n, 2->1 = n
- decision  : <keep / revert / next step>
```

## E0 · 2026-09-26 · Pipeline self-test (SYNTHETIC — not evidence)

- changed   : n/a — first run of the skeleton
- command   : `make demo`
- data      : **synthetic** (130 source images, 1631 crops, generated by
  `src/data/make_sample_data.py`)
- result    : OOF Macro-F1 = **0.79955**, accuracy 0.79522, MAE 0.20785
- confusion : adjacent-error share 0.985 (by construction of the simulator)
- decision  : **no modelling conclusion.** This number only proves the chain
  runs and the metric plumbing works. It must never be quoted as a result.

### E0b · leakage demonstration (the reason the split is grouped)

- changed   : split strategy — grouped-by-source vs. random-per-image
- predictor : a "source-memorising" model (predicts each val crop with its
  source's majority training label)
- result    : grouped = **0.20279**, random per-image = **0.56263**
- **inflation = +0.35984 (+35.98 pp)**
- decision  : the random split is not merely optimistic, it is worthless. The
  grouped split and its leakage assertion (`src/data/split_by_source.py`) stay
  mandatory. Reproduce with `make demo` or
  `pytest tests/test_pipeline_smoke.py::test_grouped_split_beats_leakage_on_source_memoriser`.

## Planned experiments (in priority order, once data lands)

| ID | Hypothesis | Single variable | Gate |
|---|---|---|---|
| E1 | A pretrained classifier beats the majority-class baseline | backbone vs. majority | OOF > majority-class F1 |
| E2 | `convnext_tiny` vs `swin_tiny` at 224 | backbone | ≥ 0.5 pp to switch |
| E3 | 384 input beats 224 | `train.image_size` | ≥ 0.5 pp |
| E4 | flip-TTA helps on *this* task | `tta.hflip` | ≥ 0.3 pp, else revert |
| E5 | multi-scale TTA helps | `tta.scales` | ≥ 0.3 pp |
| E6 | 5-fold soft-voting beats the best single fold | ensemble vs. single | ≥ 0.5 pp |
| E7 | light RandAugment helps | `aug.randaugment` | ≥ 0.5 pp |
| E8 | label smoothing 0.1 vs 0.0 | `train.label_smoothing` | ≥ 0.3 pp |

**Explicitly forbidden without a local falsification experiment:** MixUp, CutMix.
They blend images and therefore blur exactly the fine ordinal colour difference
the task is about. Recorded in
`configs/default.yaml::train.forbidden_augmentations`.

**Prior to be suspicious of:** the HardLane repo found flip-TTA to be *negative*
on lane detection. That is a different task and is **not** evidence here — E4
must be measured, not assumed.
